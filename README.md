#  Taxi Game Simulation

**Modeling taxi driver behavior and dynamic pricing using game theory**
*(Моделирование поведения водителей такси и динамического ценообразования с использованием теории игр)*

---

##  Overview

Этот проект моделирует работу сервиса такси как некооперативную игру между водителями.
Каждый водитель действует рационально и выбирает стратегию, максимизирующую личный доход.
Платформа регулирует цены с помощью динамического ценообразования, чтобы выровнять дисбаланс между спросом и предложением в разных зонах города.

---

##  Goals

* Смоделировать дисбаланс спроса и предложения в городских зонах.
* Реализовать алгоритмы динамического ценообразования (surge pricing).
* Создать поведение агентов-водителей: выбор зоны, принятие заказов.
* Изучить, возникает ли равновесие Нэша при разных настройках системы.
* Построить визуализации и собрать статистику симуляции.

---

##  Features

* Несколько городских зон с разным уровнем спроса.
* Появление заказов на основе вероятностной модели.
* Поведение водителей: выбор заказов и перемещение между зонами.
* Динамическое изменение цен в зависимости от спроса и количества водителей.
* Аналитика: доходы водителей, выполненные заказы, загрузка зон.
* Визуализация работы системы.

---

##  Project Structure

* **core** — базовые классы модели (водители, зоны, заказы, симуляция).
* **algorithms** — логика поведения водителей и алгоритмы ценообразования.
* **utils** — статистика, визуализация, вспомогательные функции.
* **data** — параметры зон и конфигурации симуляции.
* **main** — точка запуска симуляции.

---

##  How It Works

* В каждом шаге симуляции генерируются новые заказы.
* Водители принимают решения: взять заказ или переместиться в более выгодную зону.
* Платформа пересчитывает динамический множитель цены для каждой зоны.
* Система стремится достичь состояния, где распределение водителей становится стабильным.
